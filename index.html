ANTES DE DECIDIR

LAS DUDAS
MÁS IMPORTANTES.

¿Para qué una web si ya tengo Instagram o LinkedIn?

Las redes sirven para generar conversaciones. Tu web reúne el perfil, la propuesta y el portfolio que querés compartir sin depender de que alguien recorra tus publicaciones. Es un link que podés enviar después de una presentación o incluir en tu perfil.

¿Qué necesito entregar para empezar?

Tu recorrido o servicios, datos de contacto, logo si tenés y fotos o materiales que estés autorizado a usar. Recibís una lista según tu perfil. Los textos se organizan a partir de esa información y se validan con vos.

¿Cuándo se entrega y cómo se paga?

La propuesta define el plazo, las fechas de revisión y la forma de pago antes de empezar. La fecha depende del alcance y de recibir los materiales completos. Los cambios fuera del alcance se acuerdan por separado.

¿La web queda a mi nombre?

Recibís los archivos de tu web y una guía de uso. El dominio y las cuentas de servicios se gestionan a tu nombre. El alcance base es una web de contenido fijo; un panel para editarla por tu cuenta se cotiza aparte.

¿Sirve si ya tengo una web?

Sí. Primero se revisa qué conviene conservar y qué necesita mejorar. Si hay contenido que migrar o integraciones existentes, se incluyen en el presupuesto antes de avanzar.

¿Incluye conseguir clientes o gestionar mis redes?

Incluye una web preparada para presentar tu trabajo y facilitar el contacto. La captación, la gestión de redes y el cierre comercial requieren trabajo propio y no están incluidos en el alcance base.
